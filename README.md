# Personal Mini-Toolkit

## Project Overview
The **Personal Mini-Toolkit** is a menu-driven Python application developed as the Week 8 Final Project. It brings together core programming fundamentals including variables, loops, conditionals, mutable lists, and functions.

## Included Tools
1. **To-Do List Manager**: Allows users to view, add, and remove tasks dynamically from an active list during execution.
2. **Number Guessing Game**: Generates a random secret number between 1 and 50 and provides higher/lower hints until the user guesses correctly.
3. **Tip & Split Calculator**: Computes tip totals, overall bills, and individual split amounts based on user input.
